# 葡萄疏果识别图像处理算法

生物生产机器人设计，第 3 题。**当前为开发检查点，不是已完成的可提交成果。**

目标：识别葡萄果粒，按可调阈值标出建议去除的可见果粒，并统计保留数量；补充阳光玫瑰花序识别。交付程序、训练权重、独立测试结果和论文。

## 已完成

- 核对课件第 3 题及课程论文要求（至少 1500 字，图文、文献与设计程序）。
- 下载花序数据 1387 张及标签，其中 567 张原始 JPG、820 张已有增强图。不能把增强图当独立样本随机划分。
- 下载 GBISC 150 张图及 50718 个实例标注，含阳光玫瑰、巨峰、夏黑各 50 张。
- 检查 GBISC 阶段：主要为较大果粒，**不能作为幼果数据替代品**。真实疏果期幼果数据仍需补充。
- 编写 GBISC 转换脚本，先按品种和连续拍摄序号每 5 张分组，再划分、裁图；统一原始 JSON 中不一致的类别编号。
- 按 90/30/30 张原图划分 train/val/test，生成 360/120/120 个图块；记录每张原图 SHA256。
- 开始 YOLOv8n CPU 辅助训练，25 epochs，384 输入，冻结前 10 层，seed=20261010。尚无最终测试结论。

## 文件与恢复

## 结果表述边界

单张图像只能统计可见果粒；全穗农业目标不能直接等同正面照片的计数。相对尺寸阈值是待验证工程参数，不是假定已有农艺结论。邻近文件名分组不能保证所有同场景照片均被隔离，还需近重复审计。没有完成的训练、测试及幼果适配不会写成完成。
