# 摘要与设计目标


针对阳光玫瑰葡萄疏果中的查数与小果筛选需求，设计目标检测、单穗区域选择、相对尺度判别和结果导出程序。系统以YOLOv8n为基础，分别训练花序与小穗、辅助果粒及幼果弱标注模型；按检测框投影尺度产生可复查的疏除建议，输出编号图、CSV和JSON。


三组模型各实际训练25轮。辅助果粒独立测试120图块的固定阈值F1为0.7467；幼果试验仅2个区域78个视觉辅助检查框，F1为0.8800，计数MAE为3.00粒。幼果标签未经专家复核，结果仅支持小规模算法流程试验。程序能够守恒统计可见保留数量，但不估算隐藏果粒，也不直接控制机械剪切。


关键词：阳光玫瑰；疏果；YOLOv8；可见果粒计数；相对尺度


# 1 研究背景与任务要求


传统颜色和形状方法容易把绿色叶片、果梗与幼果混淆。Mask-GK采用实例掩膜高斯核进行果粒分割计数[1]；MVDNet利用计数与果穗分割双分支研究疏果期计数[2]。本设计不提出新网络结构，而是在普通CPU上完成真实数据清洗、检测、阈值筛选与可追溯导出[3]。


公开精品果指标中，马陆阳光玫瑰为45—50粒每串[4]，但它不是照片可见果粒的统一目标。栽培记录强调小粒、内向粒等取舍[5]。二维照片难以判断果梗朝向，因此默认只比较相对大小，保留上限由用户按所框区域设置。

# 3 算法结构与设计程序


![图4 检测 筛选及结果导出的功能关系](figures/system_design.png)


输入图像先由用户框选单穗。大区域使用1024像素窗口和768像素步长，坐标回到原图后以NMS消除重复框。模型输入固定填充到384像素，避免单图与批量填充方式不同造成计数差异。花序分支直接输出整花序与小穗数量，果粒分支继续筛选。


第i个检测框宽高为wᵢ、hᵢ，投影尺度dᵢ=√(wᵢhᵢ)，相对尺度rᵢ=dᵢ/median(d)。当rᵢ<τ时建议去除，默认τ=0.70。它衡量二维框大小，透视与遮挡会影响判断，不能视作真实直径。


若设置可见保留上限K，则在大小筛选后，从中心距离除以平均尺度最小的一对中优先去除较小者，迭代至数量不超过K。输出保持N=Nᵣ+Nₖ，不推算不存在的对象。每粒保存编号、位置、尺度、动作和原因供人工复查。

# 8 结论与交付复现


本设计完成三组实际训练及可见目标识别、相对大小筛选、可调上限和结构化导出。训练数据、曲线、混淆矩阵与失败案例均保留来源路径，便于检查“样本—训练—验证—测试—程序输出”的对应关系。当前可作为课程算法原型，尚无整穗隐藏粒数、田间疏除正确率或机械剪切精度的证据。


后续应优先扩大跨果园、跨光照的独立幼果样本，并由双人或专家复核标签，再考虑实例分割与果梗朝向。继续追求更高小样本分数不足以消除上述限制。
