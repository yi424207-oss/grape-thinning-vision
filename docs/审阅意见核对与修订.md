# 审阅意见核对与修订

本记录对应第二版论文的外部审阅意见。结论以原始评测JSON、DOCX表格、程序源码和本轮实际复验为依据。

## 先核对数值

- 辅助果粒原始TP=6219、FP=827、FN=3393，F1=2TP/(2TP+FP+FN)=0.7466682674990995。第二版摘要为0.7467，DOCX表格为0.747，属于显示精度不同；未找到0.7472。修订版统一F1为四位小数。
- 第二版敏感性表的去除数是3、7、15、17、19，保留数是37、33、25、23、21。0.50行并没有去除33粒。修订没有改动这些原始数值，并增加了阈值单调性测试。
- 原程序和图表生成源码已经使用双连字符参数；修订提高可读性并明确续行，不将疑似OCR读法当成程序错误。
- 第二版已经有固定版本的requirements.txt。修订补充完整CPU依赖锁定文件、Python和实测环境说明。
- 第二版摘要已经写明幼果标签未经专家复核、仅支持小规模流程试验；修订进一步强调已验收入口和农艺边界。

## 实际修订

| 问题 | 修订和证据 |
| --- | --- |
| 场景防泄漏说明不充分 | 公开分组算法和逐组样本数；辅助按每品种连续5张原图分组，花序按编号整除10；明确未取得植株及果园身份，不能证明场景独立 |
| 品种分布 | 明确辅助模型混合三品种，均为每品种30/10/10原图；增加分品种测试结果，不声称未见品种泛化 |
| 验证测试口径 | 依据保存的预测统一使用匹配IoU=0.50，各类验证选定置信度固定用于测试；新增同口径TP/FP/FN图 |
| 背景真阴性 | 新图不设背景标签、真阴性或背景归一化列；原训练器矩阵仅保留为历史档案并解释其口径 |
| 适配对照 | 0.30、0.40、0.50相同阈值逐项比较；0.50下适配模型计数MAE更大，不再笼统写适配改善 |
| 不确定性 | 辅助与花序按拍摄编号组重采样10000次，报告条件区间及独立性假设；幼果2个同来源区域不给出具有总体解释的置信区间 |
| 多随机种子 | 本轮固定数据划分，按三个随机种子重复训练并逐次保存记录；共9次均已完成25轮，逐次权重、CSV和汇总公开，报告F1、MAE及AP的均值与样本标准差 |
| AP与F1混读 | 独立测试AP单列，定义置信度下限、IoU与均值方式；原权重三组AP均实际重跑且与原值一致 |
| MAE单位 | 区分粒每图块、穗每图、小穗每图和粒每区域，不称为每穗总粒数误差 |
| 相对尺度漏检偏差 | 增加选择性删除最小框的扰动分析；不称其为新增检测性能实验 |
| 数量与字段 | 明确N_total=N_keep+N_remove；schema_version=2.0使用relative_scale替代relative_diameter，旧档案保留旧字段 |
| 花序用途 | 明确仅做定位和类别计数，不生成疏花动作，不把小穗数换算为果粒数 |
| 导出示例 | 新增真实CLI导出和keep/remove样例，说明编号、坐标、置信度、action、reason取值 |
| CPU性能 | 实测8线程、384像素、预热3次及20次计时，分别报告批量1/4吞吐、标准差、进程峰值RSS与不包含的步骤 |
| 表格与标题 | 分列三模型训练配置，统一指标精度；定位为可见果粒检测与尺度筛选算法原型 |
| 引用支撑 | 将YOLO文档引用移至YOLO选型；CPU实测由本实验记录支撑，网页栽培内容仅为背景或图像来源 |

## 仍不能由本次软件复验替代的工作

双人标注一致性、农艺专家复核和田间疏除真值尚未取得；不能编写成已完成。公开原图缺少植株和果园身份，分组审计不能弥补缺失的场景信息。桌面窗口交互验收仍需在目标电脑完成。本原型输出仅供复查，不直接控制疏除装置。

原始网络幼果照片及逐图标注不进入公开交付包，因此公开包无法独立重新训练幼果模型。发布的统计和已训练权重不等于提供了这些原图的再分发许可。
