# 葡萄疏果识别程序使用说明

交付的是离线图像算法课程原型。先选一穗，识别后复查编号图。输出数量只覆盖照片里被检测到的可见果粒，不代表整穗真实数量。

## 安装

建议 Python 3.12，使用虚拟环境。当前验证环境是 Linux CPU；Windows、macOS 尚未逐机验证。模型权重已经提供，不需要重新训练才能运行。

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# Linux/macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
```

PyTorch CPU 轮子可从 https://download.pytorch.org/whl/cpu 安装。若标准 PyPI 暂无记录中的版本，先按该官方索引安装 torch/torchvision，再安装其余依赖。不要用不明来源的模型或轮子。Linux 桌面入口还需要发行版的 python3-tk。

## 最先验证命令行

交付包内有 CC BY 4.0 的两张演示图，署名见 DATA_SOURCES.md。

```bash
python src/predict.py examples/berry_demo_input.jpg --weights runs/berry_aux/weights/best.pt --output outputs/my_result --confidence 0.30 --ratio 0.70
python src/flower_predict.py examples/flower_demo_input.jpg --weights runs/flower/weights/best.pt --output outputs/my_flower --confidence 0.25
```

输入自己的幼果照片：

```bash
python src/predict.py my_grape.jpg --weights runs/young/weights/best.pt --output outputs/my_young --confidence 0.40 --ratio 0.70
```

可用 `--roi x0 y0 x1 y1` 限定原图中一个果穗。若不框选而输入多个果穗，计数就是全部检测对象的总和。`--visible-target 30` 表示“当前区域可见果粒最多保留30粒”，绝不能直接等同于“整穗最终保留30粒”。默认不设置上限。

## 桌面界面

```bash
python src/app.py
```

打开照片后，用鼠标拖框选择单穗。选择辅助果粒、幼果试验或花序模型，输入置信度和小果比例，点击“识别并导出”。保留上限可以留空。绿色框为保留，红色框为建议去除。

桌面界面只完成源码和导入检查；当前计算环境无法打开图形服务连接，因此尚未完成窗口拖框和按钮交互验收。已实际验证的入口是命令行。若界面在目标电脑报错，先运行上面的 CLI 检查依赖和模型。

## 查看结果

果粒目录包含 annotated.jpg、berries.csv、result.json。JSON 记录 ROI、输入尺寸、阈值、耗时、每粒的位置和筛选原因。检查 visible_count = keep_count + remove_count。CSV 可用表格软件打开，采用 UTF-8 BOM。花序模式输出 inflorescence 和 spikelet，后者是小穗，不能当作单花或果粒。

## 复现训练与评测

从 checkpoint-001 Release 下载两个原始数据附件，解压至 data/gbisc_original 与 data/flower_original。

```bash
python scripts/prepare_data.py
python scripts/prepare_flower.py
python scripts/train.py
python scripts/train_flower.py
python scripts/evaluate.py --task berry_aux
python scripts/evaluate.py --task flower
python scripts/audit_duplicates.py
python -m unittest discover -s tests -v
```

幼果候选原件私人恢复档案另行保存。公开复现可用 `python scripts/recover_young_photos.py`，来源可能失效，失败信息在 data/young_candidates/recovery_validation.json。然后运行 prepare_young.py、train_young.py、evaluate.py --task young。外部评测区域和视觉辅助标注见 annotations/young_review.json；未经专家复核。原始网络照片的使用和转载依各来源授权。

```bash
python scripts/prepare_young.py
python scripts/train_young.py
python scripts/evaluate.py --task young
python scripts/evaluate.py --task young --weights runs/berry_aux/weights/best.pt --report-name young_baseline
python scripts/verify_delivery.py
```

数据路径根据脚本所在目录生成，移动项目后先重跑数据准备。评测固定输入384、IoU匹配0.50；置信度只用验证集选择。论文的 AP 与固定阈值 P/R/F1 来自不同统计流程，不能混写。

## 验收与已知限制

- 三组模型都实际训练25轮，权重和 CSV 可核验。
- 6项筛选单元测试及命令行端到端检查已通过。
- 辅助果粒测试120图块，原图30张；花序测试79张。
- 幼果训练37张弱标注实拍，验证1个区域，测试2个区域78个视觉框。该规模不足以支持田间准确率结论。
- 未验证真实疏果正确率；默认0.70是工程参数。
- 图像可见数量不含隐藏果粒，不能用它直接控制机器人剪切。


论文DOCX使用Noto Serif CJK SC字体，PDF已嵌入字体。重建论文另安装requirements-report.txt和Noto CJK字体；图形脚本可以设置GRAPE_CJK_FONT为本机字体文件。
